# Seat Shuffle

A classroom seat-shuffling timer for Room 16 (36 desks: rows of 4, center aisle, rows of 4).

- Choose which desks are in use.
- Each student starts at their home seat (student 12 at desk 12).
- Set how often to shuffle and how long students get to move.
- Project the big-screen view: every student sees their number and their next desk. Nobody stays in the same seat.

Settings and names are saved only in the browser you use. Nothing is sent anywhere.

It's a single file, `index.html`, with no build step. It's hosted on GitHub Pages.
